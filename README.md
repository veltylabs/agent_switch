# agent-switch
<img src="docs/img/badges.svg">

Append-only runtime switch for AI agent enable/disable. Every state change is persisted
as a new row; the latest row represents the current state. Never mutate or delete rows.

## Ops

| Op | Action | Resource | Args | Description |
|---|---|---|---|---|
| `get_agent_status` | `r` (`model.Read`) | `agent_switch` | none | Returns current enabled state, actor, timestamp, and reason — or an empty result if the log has never been toggled |
| `toggle_agent_status` | `u` (`model.Update`) | `agent_switch` | `ToggleArgs{IsEnabled, ChangedBy, Reason}` | Inserts a new audit row (enable or disable); `ChangedBy` is required |

## Constraints

- **Append-only:** INSERT only. No UPDATE, no DELETE.
- `New(db, deps)` handles its own migration by calling `ddl.New(db.RawConn(), ddlCompiler).CreateTable(&AgentSwitch{})` if the connection supports it.
- `changed_by` MUST be non-empty; validated before writing.
- `ID` is generated by `model.IDGenerator`.
- `changed_at` is an explicit timestamp set via `time.Now()` at insert time.

## Key Files

| File | Role |
|------|------|
| `model.go` | `model.Definition` definitions for the entities and operations |
| `model_orm.go` | Auto-generated ORM helpers — DO NOT EDIT |
| `mcp.go` | `Module`, `New(db, deps)`, `GetStatus()`, `Toggle()`, `History()`, `MountOps()` |
| `tests/` | External test package utilizing `storage/mem` and `router/mock` |

## Quick Start

```go
import agentswitch "github.com/veltylabs/agent_switch"

m, err := agentswitch.New(db, agentswitch.Deps{
    IDs:       idGenerator,    // model.IDGenerator
    Publisher: eventPublisher, // events.Publisher, nil disables publishing
})   // creates table + initialises module

m.MountOps(reg)            // registers ops on router.OpRegistry
```
